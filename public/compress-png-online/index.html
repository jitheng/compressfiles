PNG vs JPEG — what changes during compression?

PNG files use lossless compression — every pixel is stored exactly. This produces large file sizes, especially for photographs. CompressFiles re-encodes your PNG as a JPEG, using JPEG's lossy compression to achieve dramatic file size reductions. The trade-off: JPEG does not support transparent pixels, so any transparent areas become white in the output.

When is PNG compression most effective?

  • Best for: Photographs, complex images with gradients, screenshots of photos or web pages
  • Less effective for: Logos, icons, flat-colour illustrations (these are already small as PNG)
  • Not suitable if: You need to preserve a transparent background
