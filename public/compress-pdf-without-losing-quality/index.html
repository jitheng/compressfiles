What actually gets compressed?

Our compressor re-encodes embedded raster images (photographs, scanned content) at a lower JPEG quality. Everything else is completely untouched:

  • Text and fonts — never modified; stays perfectly sharp at any zoom level
  • Vector graphics — logos, charts, and diagrams remain crisp
  • Form fields — all interactive elements preserved
  • Digital signatures — document integrity maintained
  • Bookmarks and links — document structure unchanged

Which level should I choose?

For documents where quality is critical — CVs, contracts, medical records, print-ready files — choose Low. For everyday sharing via email or Slack, Medium hits the sweet spot between size and quality. Only use High when you have a strict file size target and can accept some image softening.

Frequently asked questions

Does compression affect text quality?

Never. Text, fonts, and vector graphics are not re-encoded. Only embedded raster images are processed. Your document text stays perfectly legible at any zoom level regardless of compression level chosen.

Which level should I use for a CV or contract?

Medium compression is ideal for CVs, contracts, and professional documents. It significantly reduces file size while keeping all text crisp and any photos at good quality. If the document contains no photographs, even High compression won't visibly affect quality.

Can I preview the quality before downloading?

The download is immediate after compression. If you're unsure, start with Medium and try High only if the result is still too large. Most documents look identical on-screen with Medium compression.
